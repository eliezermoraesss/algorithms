# 🧠 Estudos de Algoritmos em Java

Este repositório reúne **exercícios e implementações de algoritmos clássicos em Java**, com foco em **análise assintótica, complexidade computacional** e **estruturas de dados**.  
O objetivo é **aprofundar o entendimento prático e teórico sobre eficiência algorítmica**, desenvolvendo raciocínio lógico e boas práticas de programação.

---

## 🗂️ Estrutura do Projeto

| Diretório / Seção | Descrição |
|--------------------|------------|
| **`src/algorithms/`** | Implementações de algoritmos em Java |
| **Exercícios** | Problemas e desafios de lógica |
| **Análise Assintótica** | Estudo das notações **O**, **Ω** e **Θ** |
| **Complexidade Computacional** | Comparação de tempo e espaço entre algoritmos |

---

## ⚙️ Algoritmos Implementados

### 🔄 Ordenação
- `BubbleSort` / `BubbleSort2` → Ordenação simples por trocas adjacentes
- `MergeSort` → Técnica de divisão e conquista para ordenação eficiente
- `QuickSort` → Algoritmo rápido baseado em particionamento recursivo

### 🔍 Busca
- `BinarySearch` / `BinarySearch2` → Busca binária em arrays ordenados
- `BruteForceSearch` → Busca sequencial (força bruta)

### 🔤 Manipulação de Strings
- `AnagramCheck` → Verifica se duas strings são anagramas
- `CountCharacterFrequency` → Conta frequência de caracteres
- `FindAllRepeatedChars` → Lista todos os caracteres repetidos
- `FirstRepeatedChar` → Retorna o primeiro caractere repetido
- `HasDuplicateChars` → Verifica duplicidades
- `Palindrome` → Verifica se uma string é palíndromo
- `ReverseString` → Inverte uma string

### 🔢 Números e Matemática
- `FibonacciIterative`, `FibonacciRecursive` → Cálculo da sequência Fibonacci (iterativo e recursivo)
- `FindMaxNumber` / `MinMaxNumber` → Encontra maior e menor número
- `FindMaxSum` → Calcula a maior soma possível em um array
- `FindMaxSumNumber` → Busca números que somam um valor específico
- `EvenSum` / `OddSum` → Soma de pares e ímpares
- `TwoSum` → Encontra pares de números com soma alvo
- `FindRepeatNumber` → Detecta números repetidos

### 🧩 Estruturas e Técnicas
- `FilterFirstLetterArrayList` / `FilterFirstLetterArrayList2` → Filtragem por primeira letra
- `SlindingWindow` → Implementação da técnica de **janela deslizante**

### 🚀 Exercícios e Otimização
- `AlgorithmExercises` → Exercícios gerais de algoritmos
- `AlgorithmsOtimizationExercises` → Foco em otimização e eficiência
